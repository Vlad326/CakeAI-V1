# CakeAI-V1

[English](README.md) | **Русский**

Автономный боевой робот, которым управляет камера над ареной: программа
находит своего робота по ArUco-маркеру, противника — по движению и
управляет роботом через Arduino. Человек за пультом не нужен.

Это версия, с которой робот CakeAI (Торт ИИ) выступал на
[Крашилово](https://crashilovo.ru/) 25 апреля 2026 года. Актуальная версия закрыта.

https://github.com/user-attachments/assets/5153ef42-87cf-4e12-afa7-24857af2e5f4

## Как это работает

- **Камера над ареной** видит всё поле.
- **Свой робот:** положение и направление — по ArUco-маркеру сверху.
- **Противник:** детекция движения между кадрами, свой робот при этом
  исключается.
- **Поведение:** возврат в центр → атака → поиск, если противник потерян;
  к цели робот доворачивает PID-регулятор.
- **Arduino** получает команды езды и оружия по последовательному порту
  (прошивка: `src/ArduinoProgram.ino`).
- **Панель управления** для настройки на лету; значения сохраняются в `config.ini`.

**Стек:** C++17, OpenCV 4, CMake, Windows (MSYS2 UCRT64), Arduino.

## Скачать

В терминале **MSYS2 UCRT64**:

```bash
pacman -S git
git clone https://github.com/Vlad326/CakeAI-V1.git
cd CakeAI-V1
```

## Сборка

Установить компилятор, CMake и OpenCV (один раз):

```bash
pacman -S mingw-w64-ucrt-x86_64-gcc mingw-w64-ucrt-x86_64-cmake mingw-w64-ucrt-x86_64-make mingw-w64-ucrt-x86_64-opencv
```

Собрать:

```bash
mkdir -p build && cd build
cmake -G "MinGW Makefiles" ..
mingw32-make
```

Запустить:

```bash
./main.exe
```

В `build/config.ini` лежат настройки, с которыми CakeAI выступал на
Крашилово (25 апреля 2026 года): они подобраны под тот робот, камеру и
арену. Программа читает этот файл из папки, в которой её запустили.

**Внимание:** при выходе программа сохраняет текущие значения панели в
`config.ini` и перезаписывает его.

Перед первым запуском проверьте:

- **Порт Arduino** зашит в `src/main.cpp` как `COM3` — поменяйте на свой.
- **Экспозиция камеры** из `config.ini` при запуске не применяется —
  выставьте её под своё освещение в панели управления и нажмите **Apply**.
  Программа использует первую камеру (индекс 0).

Чтобы управлять настоящим роботом, нужны камера и Arduino с прошивкой
выше. Параметры настроены под конкретного робота, камеру и арену —
под своего их придётся подбирать заново.
